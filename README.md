# 구구단성의 보물 v1.0

## 바로 해보기
`index.html` 을 더블클릭하면 실행됩니다.

## 폴더
```
index.html        화면 구조
manifest.json     홈 화면에 추가용
css/style.css     디자인
js/data.js        ★ 몬스터·아이템·상점·난이도·보상 (밸런스는 여기만 고치면 됩니다)
js/save.js        저장 (기기)
js/sync.js        ★ 기기 간 이어하기 (Firebase 설정 넣는 곳)
js/audio.js       효과음·음악·몬스터 음성
js/core.js        화면 전환·공용
js/map.js         지도·이동·펫
js/train.js       훈련소
js/battle.js      전투·퍼즐방
js/main.js        시작화면·상점·설정
img/              그림 25장
songs/            song-2.mp3 ~ song-9.mp3 (넣으면 자동 재생)
voice/            ask-2-1.mp3 / ans-2-1.mp3 ... (넣으면 TTS 대신 사용)
```

## 진행 순서
첫 자리는 2단으로 고정이고, 몬스터를 이길 때마다 다음에 도전할 단을 직접 고릅니다.
고르기 전까지 지도에는 `???` 로 잠겨 보입니다.
추천 순서는 `js/data.js` 의 `TABLE_TIP` 에서 `lv` 숫자로 조절합니다 (낮을수록 위에 표시).

## 자주 고칠 값 — js/data.js
- `DIFF` : 난이도별 제한시간·하트·골드 배율
- `REWARD` : 몬스터당 골드
- `SHOP` : 상점 물건과 가격
- `PET.stages` : 펫이 자라는 데 필요한 정답 수
- `TABLE_TIP` : 단별 추천 순서와 설명
- `FIRST_TABLE` : 시작 단 (기본 2단)

## 기기 간 이어하기 (선택)
1. Firebase 콘솔에서 새 프로젝트 생성
2. Firestore 데이터베이스 만들기 + Authentication 에서 익명 로그인 켜기
3. 웹 앱 추가 후 설정값을 `js/sync.js` 의 `FIREBASE_CONFIG` 에 붙여넣기
4. 게임 안 ⚙️ 설정에서 "코드 만들기" → 다른 기기에서 "코드 입력"

설정하지 않아도 게임은 그대로 돌아갑니다 (기기에 저장).

## 주의
카카오톡 안에서 열면 진행이 저장되지 않을 수 있습니다.
링크를 연 뒤 "브라우저로 열기" → "홈 화면에 추가" 로 쓰세요.

## 변경 기록
### v1.1
- 진행 순서 자유화: 2단 이후 다음 단을 직접 선택 (갈림길 화면)
- 지도의 미배정 자리는 `???` 로 표시

### v1.0
- 자동 저장 · 이어하기
- 난이도 3단계 (연습 / 모험 / 챔피언)
- 골드 · 몬스터별 수집 아이템 · 상점
- 포션 3종 (훈련 완료 시 선택)
- 퍼즐방 (틀린 문제만 복습 후 시간제한 없는 재대결)
- 아기 드래곤 펫 (지도에서 따라다님, 3단계 성장)
- 파일 분리 (js 9개)

### v1.2
- 모바일에서 화면 아래가 잘리고 스크롤되지 않던 문제 수정
  (고정 높이 100dvh → 실제 화면 높이 측정 + 세로 스크롤 허용)
- 훈련소 10칸 프레임이 5줄/7줄 이상이면 점 크기 자동 축소 (9x9 대응)
- 작은 화면(높이 740px / 640px 이하) 전용 크기 조정

### v1.3
- 용사 선택 화면에서 한쪽을 고르면 두 칸 모두 같은 그림으로 바뀌던 문제 수정
- 얼굴 사진은 그 사진을 넣은 용사에게만 적용되도록 변경

### v1.3.1
- 폰에서 얼굴 이미지가 안 보이던 문제 수정
  (JS가 그리던 것을 HTML에 직접 넣어, 스크립트 로드와 무관하게 표시)
- 이미지 대체 함수를 <head>에 인라인으로 이동 (로드 순서 문제 제거)
- CSS/JS에 버전 표시(?v=13) — 브라우저가 옛 파일을 계속 쓰는 문제 방지

### v1.3.2
- 용사 클릭이 안 되던 문제 수정
  원인: save.js 가 data.js 의 FIRST_TABLE 을 참조하는데 data.js 가 옛 버전이면
  save.js 전체가 죽으면서 이후 모든 기능이 멈췄음
- save.js 가 data.js 없이도 동작하도록 방어 코드 추가
- 시동 과정을 try 로 감싸 한 부분이 실패해도 화면은 살아 있도록 변경

### 파일을 부분 교체할 때 주의

게임 전체가 멈출 수 있으니, 되도록 js 폴더 9개를 모두 함께 올리세요.
